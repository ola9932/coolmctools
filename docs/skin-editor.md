# Skin Studio

## 작업실 편의 기능

- 편집 화면 왼쪽 아래에 채도·명도 면과 세로 색조 막대가 있는 컬러피커를 항상 표시합니다. HEX와 H/S/V 숫자 입력, 팔레트, 스포이트가 같은 그리기 색상으로 동기화됩니다. 키보드 사용 시 색조 슬라이더와 H/S/V 숫자 입력을 이용할 수 있습니다.

- 움직임 목록에서 앉은 자세·누운 자세를 선택할 수 있습니다. 일시 정지 중에도 자세 전환은 즉시 반영됩니다.
- 상단 고정 도구막대에 그리기 팔레트와 현재 색상의 RGB 값을 표시합니다.
- 레퍼런스 색상 선택 중 3D 모델 또는 2D 펼침도에 포인터를 올리면 주변 픽셀을 확대합니다.
- 헤더에서 다크/화이트 모드를 전환하며 선택한 테마는 브라우저에 저장됩니다.
- 상단 레이어 메뉴에서 기본층과 외부층 표시를 켜거나 끕니다. 숨겨진 편집 레이어에는 그릴 수 없습니다. 레이어를 다시 선택하면 해당 층이 표시됩니다.
- `L`은 레이어 메뉴, `P`는 신체 부위 메뉴를 엽니다. 텍스트 입력 중에는 단축키가 작동하지 않습니다.
- 추출 팔레트는 색상과 작은 비율만 표시합니다. HEX 코드는 마우스를 올려 확인하거나 색상을 선택해 편집 색상 입력에서 확인할 수 있습니다.

마인크래프트 도구 모음의 첫 기능인 브라우저 스킨 에디터입니다.

## 실행

- 의존성 설치: `npm ci`
- 로컬 실행: `npm run dev`
- 프로덕션 빌드: `npm run build` (`dist/` 생성)
- 코드 검사: `npm run lint`
- 핵심 로직 테스트: `npm test`
- 브라우저 테스트: `npm run test:e2e` (Microsoft Edge 설치 필요)

브라우저 테스트는 필요한 경우 개발 서버를 시작합니다. 로컬에서 이미 실행 중인 5173 포트의 서버도 사용할 수 있습니다.

## 기능

- 3D 모델 직접 그리기와 2D 펼침도 편집
- 펜, 지우개, 스포이트, 현재 면 안의 연결 영역 채우기
- 기본층 / 외부층 선택, 외부층 표시 전환, 부위 숨기기
- Classic / Slim 모델 선택, 픽셀 격자와 포인터 강조
- 스트로크 단위 실행 취소 / 다시 실행 (최대 100개)
- 64×64 PNG 불러오기 / 다운로드
- 로컬 자동 저장과 새로고침 후 복원
- skinview3d 기반 별도 애니메이션 미리보기: 서 있기, 걷기, 달리기, 손 흔들기, 날기, 웅크리기
- 애니메이션 속도, 일시 정지, 자동 회전
- 모바일 반응형 레이아웃
- 같은 페이지에서 레퍼런스 ON/OFF, 나란히/작은 창 배치, 애니메이션 탭 전환
- 레퍼런스 PNG 최대 8개 추가·교체·제거 및 드롭다운 선택, 개별 모델 설정
- 레퍼런스 3D/2D 표시, 시점 동기화, 부위·레이어 필터, 스포이트
- 부위·면·2D 사각형 합성: 미리보기 후 적용, 투명 픽셀 포함 여부 선택, 실행 취소
- 편집/레퍼런스의 부위·레이어별 실제 RGB 팔레트, 빈도 표시, 색상 최대 32개 고정
- 레퍼런스 목록과 고정 팔레트의 브라우저 저장·복원

## 레퍼런스 사용

데스크톱 나란히 보기에서는 편집 스킨과 레퍼런스의 영역 너비·높이·시작 위치를 맞추고 같은 배경으로 연결해 표시합니다. 시점 동기화를 켜면 카메라 방향·거리·화각을 공유합니다. 레퍼런스의 부위 및 기본층·외부층 표시는 편집 설정을 따르며, 레퍼런스 모델 유형은 독립적으로 선택합니다. 표시 동기화는 작은 창과 모바일 보기에서도 유지됩니다.

상단의 레퍼런스 추가에서 PNG를 선택합니다. 레퍼런스를 켜면 상세 편집 설정이 접히고 두 모델이 나란히 표시됩니다. 설정은 다시 펼칠 수 있습니다. 모바일에서는 편집 / 참고·미리보기 버튼으로 같은 페이지 안에서 전환합니다.

레퍼런스 색상 선택을 켠 뒤 3D 또는 2D 픽셀을 클릭하면 그리기 색상이 바뀝니다. 기본층과 외부층을 함께 표시할 때 3D 스포이트는 투명한 외부층을 건너뛰고 실제 색이 있는 표면을 선택합니다.

부위 / 영역 합성에서 대상 부위, 레이어, 복사 범위를 지정합니다. 사각형 범위는 레퍼런스 펼침도에서 드래그하며, 선택한 부위·레이어와 겹치는 픽셀만 같은 좌표에 복사합니다. 미리보기 취소는 작업을 변경하지 않고, 적용 한 번은 실행 취소 한 번으로 복구됩니다. 모델이 서로 다르면 팔 합성을 차단합니다. 머리·몸통·다리는 합성할 수 있습니다.

아래 팔레트 추출 패널에서는 현재 편집 스킨 또는 선택한 레퍼런스의 부위·레이어를 고릅니다. RGB별 사용 픽셀 수로 비율을 계산하며 완전히 투명한 픽셀과 미사용 영역은 제외합니다. 반투명 픽셀은 해당 RGB의 픽셀 하나로 집계합니다. 색상 클릭 후 현재 색상 고정을 누르면 재사용할 수 있습니다.

## 조작

| 조작                      | 기능                                   |
| ------------------------- | -------------------------------------- |
| 왼쪽 드래그               | 선택한 도구로 그리기                   |
| 오른쪽 드래그 / 회전 도구 | 3D 카메라 회전                         |
| 휠 / + / −                | 확대·축소                              |
| B / E / G / I / R         | 펜 / 지우개 / 채우기 / 스포이트 / 회전 |
| Ctrl 또는 Cmd + Z         | 실행 취소                              |
| Ctrl 또는 Cmd + Shift + Z | 다시 실행                              |

터치에서는 회전 도구를 선택해 모델을 돌립니다. 2D 펼침도는 선택한 레이어와 표시 중인 부위만 편집할 수 있습니다.

## 구조

- `src/skin.js`: 순수 픽셀 연산, 면별 UV 영역, 이력
- `src/views.js`: skinview3d 모델, 3D 픽셀 선택, 카메라, 미리보기 애니메이션
- `src/main.js`: 입력, 파일 처리, 저장, 화면 상태
- `src/style.css`: 반응형 작업실 UI
- `src/reference-data.js`: 합성 마스크, 팔레트 집계, PNG 검증
- `src/references.js`, `src/reference.css`: 한 페이지 레퍼런스·합성·팔레트 UI

원본 RGBA 배열 하나를 Canvas에 반영하고 3D 편집기와 미리보기가 같은 텍스처를 공유합니다. 격자와 포인터는 별도 표시이므로 다운로드 PNG에 포함되지 않습니다. 편집용 부위 숨김은 완성된 캐릭터 미리보기와 내보내기에 영향을 주지 않습니다.

## 현재 지원 범위

- 64×64 PNG만 지원합니다. 구형 64×32 및 고해상도 스킨은 지원하지 않습니다.
- 모델 선택은 표시 및 편집 좌표만 변경하며, Classic과 Slim 사이의 픽셀 자동 변환은 하지 않습니다.
- 투명도를 보존해 내보냅니다. 게임에서 기본층 투명도를 표현하는 방식은 편집기와 다를 수 있습니다.
- 자동 저장은 현재 브라우저의 마지막 작업 하나입니다. 사이트 데이터 삭제 또는 다른 브라우저에서는 복구할 수 없으므로 PNG로 보관하세요.
- 레퍼런스는 별도 브라우저 저장 항목으로 보관합니다. 저장 공간 부족 또는 저장 차단 시 안내를 표시하며, 새로고침 전 원본 파일을 보관해야 합니다.
- 머리카락이나 옷을 자동 인식하지 않습니다. 부위 전체 합성은 얼굴·피부도 포함할 수 있으므로 레이어·영역 선택으로 범위를 좁히세요.
- 3D에는 WebGL이 필요합니다. 사용할 수 없으면 2D 편집으로 전환합니다.
- 서버 저장, 계정 연동, 게임 계정에 직접 적용, 대칭 그리기, Auto Tone은 포함하지 않습니다.
